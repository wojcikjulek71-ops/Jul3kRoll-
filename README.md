# Jul3kRoll-

Przeglądarkowa symulacja kasyna z grami Coin Flip, ruletką europejską i blackjackiem.

## Funkcje

- Nowa gra zaczyna się od 1000 wirtualnej gotówki.
- Na stronie Bank można wpłacać gotówkę i wypłacać ją z powrotem.
- Salda i rekord są zapisywane lokalnie w przeglądarce.
- Ruletka obsługuje zakłady na liczby, kolory, tuziny i kolumny.
- W blackjacku stawki są parzyste, dzięki czemu wypłata 3:2 jest dokładna.

Otwórz `Stronaglowna.html` w przeglądarce, aby rozpocząć.
